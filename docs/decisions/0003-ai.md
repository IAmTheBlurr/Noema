# ADR 0003: Genkit behind an internal AI contract

- Status: Accepted
- Date: 2026-07-23

## Decision

Use Firebase Genkit in second-generation Cloud Functions for the real Gemini adapter, with an in-process deterministic mock adapter for credential-free local use. Only an authenticated, environment-gated connectivity/reflection callable is exposed.

## Rationale

Genkit has an official Firebase Functions integration, typed flows, auth policies, and a direct path to Gemini. The application contract remains provider-neutral. Prompts and responses are not persisted or logged.

## Safety

The Gemini key is declared with Firebase Secret Manager and never reaches browser code. Returned reflections are previews, not entry mutations. Future persistence must include model, provider, prompt-template version, invocation time, source entry ID, assumptions, and an explicit approval state.
